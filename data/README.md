# Public data bundle

- `chicago_community_area_composition.csv` is the 77-by-five CMAP-derived
  composition table used by the Chicago notebook.
- `Chicago77.shp`, `Chicago77.shx`, and `Chicago77.dbf` supply the community-area
  geometry. Keep `Chicago77_LICENSE.txt` and `Chicago77_README.md` with them.
- `california_commuting_input.npz` is the compact, pickle-free input for the
  county commuting-tensor notebook.
- `meteoswiss.csv` is the public phenological observation file used to build
  the two-era station phases. Source: MeteoSwiss.
- `*_source.json` files record immutable provenance, redistribution terms,
  preparation details, schemas, and checksums.
- `paper_scale_summary.json` contains the manuscript-scale permutation settings
  and numerical summaries for all four studies.

See `../DATA_SOURCES.md` before redistributing these files or publishing a
derived repository.
